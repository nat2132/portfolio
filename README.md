# Natoli Adugna — Portfolio

My personal developer portfolio, built with **Next.js 14**, **Tailwind CSS**, **Framer Motion** and Aceternity-UI-style components. Static-exported and deployed on **Vercel**.

## Sections

- **Hero** — intro + call to action
- **About** — bento grid with personal highlights
- **Projects** — filterable/searchable grid split into **Landing Pages** and **Full-Stack** apps, each with a live-site link and GitHub repository link
- **Skills** — technologies grouped by frontend / backend / databases / tooling
- **Experience** — selected work
- **Contact** — footer with working contact links

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build   # static export to ./out
```

## Project data

All project metadata (title, category, tech stack, live URL, repository) lives in
[`data/index.ts`](data/index.ts). Add or update a project there and the cards,
filters and search update automatically.
